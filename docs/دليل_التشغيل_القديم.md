# نظام أركان المكان — دليل النشر

## ١. رفع الملفات إلى GitHub
1. افتح github.com واضغط **New repository**
2. الاسم: `arkan-almakan` — اختر **Private** — ثم Create
3. في الصفحة التالية اضغط **uploading an existing file**
4. اسحب **محتويات** مجلد `arkan-app` كلها (لا المجلد نفسه) إلى الصفحة
5. اضغط **Commit changes**

## ٢. النشر على Vercel
1. افتح vercel.com واضغط **Add New → Project**
2. اختر مستودع `arkan-almakan`
3. قبل الضغط على Deploy، افتح **Environment Variables** وأضف متغيرين:

| الاسم | القيمة |
|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | من Supabase: Project Settings → API → Project URL |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | من نفس الصفحة: anon public key |

> المفتاح `anon` آمن للنشر — الحماية الحقيقية في سياسات RLS داخل القاعدة.
> لا تضع أبداً المفتاح `service_role` هنا ولا في أي مكان.

4. اضغط **Deploy** وانتظر دقيقتين
5. سيعطيك رابطاً مثل `arkan-almakan.vercel.app` — افتحه وسجّل الدخول ببريدك وكلمة المرور

## ٣. عند أي تعديل لاحق
أرسل لي ما تريد تغييره، أعطيك الملف المعدّل، ترفعه على GitHub، وVercel ينشره تلقائياً خلال دقيقة.
