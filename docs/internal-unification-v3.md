# Internal Unification V3 — 20-pass scope

هذه الجولة لا تعيد تصميم أركان المكان ولا تغيّر التوكسيدو المعتمد. هدفها فصل جسم البرنامج عن البدلة وامتصاص فوائد الرقع داخل عقود ثابتة.

1. تثبيت طبقات المعمارية: core / adapters / application / presentation / skin / print.
2. إنشاء سجل صريح لرقع التوافق الحالية ومسار تقاعدها.
3. منع نمو رقع مرئية جديدة بدل امتصاص فائدتها.
4. فصل مفاتيح الجلود عن اختيار الجلد النشط.
5. إنشاء سجل للجلود القابلة للاستبدال.
6. إنشاء نقطة CSS واحدة لبدلة الشاشة الجذرية.
7. الحفاظ على ترتيب طبقات ARKAN SIGNATURE كما هو.
8. إخفاء runtimes الخاصة بالتوكسيدو خلف ActiveUISkinRuntime.
9. جعل RootLayout يجهل تفاصيل ARKAN SIGNATURE.
10. إنشاء نقطة CSS واحدة لبدلة لوحة التحكم.
11. الحفاظ على ترتيب طبقات لوحة التحكم كما هو.
12. إخفاء جسور الجلد خلف ActiveDashboardSkinRuntime.
13. جعل DashboardLayout يجهل تفاصيل جسور التوافق المرئية.
14. استخراج نموذج القدرات إلى core نقي.
15. استخراج سياسة الوصول إلى core بدل تركيبها في الشاشة.
16. عزل قراءات Supabase الخاصة بتهيئة لوحة التحكم في adapter.
17. تحويل لقطة البنية التحتية إلى قرار جلسة نقي في core.
18. إبقاء نصوص الواجهة في presentation بدل core.
19. جعل وحدات core قابلة للاختبار مباشرة دون alias خاص بالتطبيق.
20. إضافة audit دائم يمنع عودة التداخل، مع تحديث اختبارات الجلد القديمة وإضافة اختبارات سلوك للـ core.

## حدود لا يجوز كسرها

- التوكسيدو النشط يظل `signature`.
- لا تغيير مقصود في المظهر الحالي أو ترتيب CSS.
- لا تغيير في قواعد الأعمال أو الصلاحيات؛ جرى نقلها لا إعادة تعريفها.
- القبطان للطباعة مستقل عن جلد الشاشة.
- الجسور القديمة المسموح بها مسجلة صراحة ولا يسمح لها بالنمو.
